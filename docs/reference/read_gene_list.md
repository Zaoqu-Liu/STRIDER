# Read Gene List

Read a list of genes from a text file (one gene per line).

## Usage

``` r
read_gene_list(filename)
```

## Arguments

- filename:

  Path to the gene list file

## Value

A character vector of gene names

## Examples

``` r
if (FALSE) { # \dontrun{
genes <- read_gene_list("markers.txt")
} # }
```
