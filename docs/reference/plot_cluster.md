# Plot Cluster Results

Visualize spatial clustering results.

## Usage

``` r
plot_cluster(cluster_result, pt.size = 4, colors = NULL, title = NULL)
```

## Arguments

- cluster_result:

  Clustering result from spatial_cluster()

- pt.size:

  Point size (default: 4)

- colors:

  Color palette

- title:

  Plot title

## Value

A ggplot object
