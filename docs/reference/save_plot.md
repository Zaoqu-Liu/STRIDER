# Save Plot to File

Save a ggplot object to file with sensible defaults.

## Usage

``` r
save_plot(plot, filename, width = 8, height = 6, dpi = 300)
```

## Arguments

- plot:

  A ggplot object

- filename:

  Output filename

- width:

  Plot width in inches (default: 8)

- height:

  Plot height in inches (default: 6)

- dpi:

  Resolution (default: 300)
