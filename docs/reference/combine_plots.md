# Combine Multiple Plots

Combine multiple ggplot objects into a single figure.

## Usage

``` r
combine_plots(plots, ncol = 2, nrow = NULL, title = NULL)
```

## Arguments

- plots:

  List of ggplot objects

- ncol:

  Number of columns

- nrow:

  Number of rows (optional)

- title:

  Overall title

## Value

A combined plot
